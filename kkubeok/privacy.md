# 꾸벅 개인정보처리방침

시행일: 2026년 11월 25일

todayzip studio(이하 "개발자")는 꾸벅 앱(이하 "앱")을 쓰는 분의 개인정보를 소중히 다루며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 앱이 어떤 정보를 왜 처리하고 어떻게 지우는지 알려 드립니다.

## 1. 카메라 영상은 폰 밖으로 나가지 않습니다
- 앱은 공부 중 졸음·딴짓·자리 비움을 판단하려고 전면 카메라를 씁니다.
- 카메라 영상은 **폰 안에서만** 얼굴 각도와 눈 뜬 정도를 계산하는 데 쓰고 **바로 버립니다.**
- 영상·사진·얼굴 이미지는 **저장하지 않고, 개발자나 다른 사람에게 보내지도 않습니다.** 얼굴로 사람을 알아보는(얼굴 인식) 기능도 없습니다.
- 얼굴 분석에는 Google ML Kit 의 기기 내 얼굴 감지 기능을 씁니다.

## 2. 폰에만 저장되는 정보
아래 정보는 사용자의 폰 안에만 저장되고 개발자는 볼 수 없습니다.
- 공부 기록: 시작·끝 시간, 상태별 시간(집중·졸음·딴짓·자리 비움·휴식), 점수
- 설정: 민감도, 소리·진동, 하루 목표, 자세 보정값(얼굴 각도·눈 뜬 정도의 평균 숫자), 닉네임, 들어간 공부방 코드
- 앱 안의 "기록 모두 지우기" 또는 앱 삭제로 모두 지워집니다.
- 기록 내보내기(공유·다운로드 폴더 저장)는 사용자가 직접 누를 때만 하고, 보낼 곳도 사용자가 고릅니다.

## 3. 친구 공부방을 쓸 때 처리하는 정보
친구 공부방은 선택 기능입니다. 쓰지 않으면 아래 정보는 처리하지 않습니다.

| 항목 | 목적 | 누가 볼 수 있나 |
|---|---|---|
| 익명 사용자 ID (Firebase 익명 로그인, 이름·이메일·전화번호 없음) | 방 참여자 구분 | 개발자 시스템 |
| 닉네임 (최대 10자, 사용자가 정함) | 방 친구에게 표시 | 같은 방 친구 |
| 공부 상태 (집중·졸음·딴짓·자리 비움·휴식 등 글자), 오늘·이번 공부 시간, 접속 여부, 마지막 갱신 시각 | 친구 현황·순위 표시 | 같은 방 친구 |
| 방 이름·방 코드·만든 시각 | 방 운영 | 코드를 아는 사람 |
| 깨우기·응원 기록 (보낸 사람 ID·닉네임·시각) | 친구 폰에 알림 | 받는 사람 (읽으면 바로 삭제) |
| 알림 토큰 (Firebase Cloud Messaging), 공부 시작 알림 켜기 여부 | 앱이 꺼져 있을 때 친구 알림 보내기 | 개발자 시스템만 (다른 사용자는 못 봄) |
| 공부 시작 알림을 보낸 시각 | 알림이 너무 자주 가지 않게 조절 | 개발자 시스템만 |

- 저장 위치: Google Firebase (Realtime Database, 싱가포르 리전), 서버 기능은 Firebase Cloud Functions (싱가포르 리전).
- **방에서 나가면** 내 닉네임·공부 상태·받은 깨우기·알림 토큰을 바로 지웁니다.

## 4. 개인정보 처리 위탁·국외 이전
앱은 서비스 운영을 위해 아래 업체의 서비스를 씁니다. 개발자는 이 정보를 팔거나 광고에 쓰지 않습니다.

| 받는 곳 | 이전되는 나라 | 항목 | 목적 | 보유 기간 |
|---|---|---|---|---|
| Google LLC (Firebase) | 싱가포르 등 Google 데이터센터 | 3번 표의 항목 | 친구 공부방·알림 운영 | 방에서 나갈 때까지 (아래 6번) |
| Google LLC (ML Kit) | 미국 등 | 기기 정보(모델·OS), 앱 정보(패키지·버전), 기능 사용·성능 지표, 오류 코드 — **영상·얼굴 이미지는 아님** | ML Kit 품질 진단 | Google 정책에 따름 |

전송은 인터넷(HTTPS 등 암호화된 통신)으로, 해당 기능을 쓸 때 이루어집니다.

## 5. 수집하지 않는 정보
이름, 이메일, 전화번호, 연락처, 위치, 사진·영상 파일, 광고 ID. 앱에는 광고와 결제가 없습니다.

## 6. 보유 기간과 파기
- 폰에 저장된 정보: 사용자가 지우거나 앱을 삭제할 때까지.
- 친구 공부방 정보: 방에서 나가면 바로 삭제. 방을 나가지 않고 앱을 지운 경우 문의하시면 지워 드립니다.
- 공부 시작 알림 보낸 시각 기록과 방 이름 정보는 방이 쓰이지 않게 된 뒤 정리합니다.

## 7. 이용자의 권리
언제든 개인정보 열람·정정·삭제·처리 정지를 요청할 수 있습니다. 대부분은 앱에서 바로 할 수 있습니다 (닉네임 바꾸기, 방 나가기, 기록 모두 지우기). 그 밖의 요청은 아래 연락처로 보내 주세요. 지체 없이 처리합니다.

## 8. 아동의 개인정보
앱은 만 13세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만인 분은 보호자(법정대리인)의 동의를 받은 뒤 친구 공부방을 써 주세요. 혼자 측정하는 기능은 서버로 정보를 보내지 않습니다. 보호자의 동의 없이 만 14세 미만 아동의 정보가 처리된 것을 알게 되면 바로 지웁니다.

## 9. 안전성 확보 조치
- Firebase 보안 규칙으로 같은 방 참여자만 방 정보를 읽고, 본인만 자기 정보를 쓰게 막습니다. 알림 토큰은 다른 사용자가 읽을 수 없습니다.
- 모든 서버 통신은 암호화됩니다.
